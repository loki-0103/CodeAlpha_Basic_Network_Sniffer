Hardened Flask Authentication Portal

Version 2.0 (Remediated Production Baseline)

Welcome to the Remediated Secure Login Application. This software build implements robust defense-in-depth principles to completely mitigate the 7 vulnerabilities present in the vulnerable baseline.

🔒 Parameterized Queries

Queries use SQLite positional parameter binding (?), completely preventing SQL Injection (Bandit B608 clean).

🔑 PBKDF2 Password Hashing

Passwords hashed with Werkzeug's pbkdf2:sha256 salted algorithm, eliminating plaintext credential exposure.

🌿 Environment Secrets

Secrets loaded securely via python-dotenv and environment variables; zero hardcoded credentials in source control.

🛡️ Input Validation & CSRF

Strict regex whitelist on usernames and multi-factor complexity enforcement on all user-supplied passwords.

🚫 Debug Mode Disabled

Interactive Werkzeug debugger disabled (debug=False), preventing remote code execution via debug console.

🍪 Secure Cookie Flags

Session cookies configured with HttpOnly=True, SameSite=Lax, and short session lifetime.
